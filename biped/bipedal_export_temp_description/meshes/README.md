# Raw CAD Mesh Inventory (`bipedal_export_temp_description/meshes`)

Contains raw, granular STL mesh models exported from CAD assemblies prior to link merging and visual optimization.

## Key Mesh Categories
- **Servomotors**: `ax-12_1.stl`, `ax-12__1__1.stl`, `ax-12__2__1.stl`, `ax-12__3__1.stl` (Dynamixel AX-12 actuator models).
- **Power System**: `Bonka battery.stl`, `Bonka_battery__1__1.stl` (LiPo battery 3D models).
- **Femur Components**: `top_femur_1.stl`, `botom_femur_1.stl` (Individual unmerged upper/lower femur segments).
- **Tibia & Foot Links**: `tibia_1_1.stl`, `tibia_2_1.stl` (Lower leg structural links).
- **Chassis Base**: `base_link.stl`, `Configuration 1 (1).stl` (Pelvis mounting frame).
