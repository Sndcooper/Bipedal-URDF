# Exported URDF Models (`bipedal_export_temp_description/urdf`)

Raw URDF/Xacro files generated directly by CAD exporter tools.

## Included Files
- **`bipedal_export_temp.xacro`**: Primary exported Xacro containing individual motor and chassis link definitions.
- **`bipedal_clean_visual.urdf`**: Cleaned visual-only URDF for frame debugging.
- **`bipedal_export_temp_visual.urdf`**: Exported visual URDF.
- **`bipedal_export_temp.gazebo`**: Gazebo tags for intermediate export model.
- **`bipedal_export_temp.trans`**: Actuator transmissions.
- **`materials.xacro`**: Color specifications.
