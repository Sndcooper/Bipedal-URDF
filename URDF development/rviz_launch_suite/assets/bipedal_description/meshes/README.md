# 3D Mesh Assets (`bipedal_description/meshes`)

Contains high-fidelity 3D CAD mesh files in STL format used for visual rendering and collision detection in RViz and Gazebo.

## Inventory of Link Meshes
- **`base_link.stl`**: Central pelvis and torso chassis housing actuators and battery mounts.
- **`left_upper_femur.stl` & `right_upper_femur.stl`**: Upper thigh links connecting hip actuators.
- **`left_lower_femur.stl` & `right_lower_femur.stl`**: Lower thigh parallel links.
- **`left_tibia.stl` & `right_tibia.stl`**: Lower leg structural links and feet.
- **`inner_linkage_1.stl` & `inner_linkage_2.stl`**: Internal five-bar transmission linkages.
