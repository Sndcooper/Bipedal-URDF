# Launch Files (`assembly_description/launch`)

Python launch files for launching the CAD assembly model in ROS 2 environments.

## Launch Scripts
- **`display.launch.py`**: Loads `assembly.xacro`, starts `robot_state_publisher`, `joint_state_publisher_gui`, and opens RViz 2.
- **`gazebo.launch.py`**: Spawns the assembly model in Gazebo simulation world.
