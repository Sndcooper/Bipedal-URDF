# Assembly Mesh Assets (`assembly_description/meshes`)

3D STL mesh files representing merged CAD sub-assemblies for optimized simulation rendering.

## Inventory
- **`base_link.stl`**: Torso and pelvis main frame.
- **`Combined_femur_1.stl`**, **`Combined_femur__1__1.stl`**, **`Combined_femur__2__1.stl`**, **`Combined_femur__3__1.stl`**: Integrated upper and lower femur drive arms.
- **`combined_motor_tibia_1.stl`**, **`combined_motor_tibia__1__1.stl`**: Combined actuator-tibia lower leg assemblies.
- **`tibia_2_1.stl`**, **`tibia_2__1__1.stl`**: Secondary parallel lower linkages.
