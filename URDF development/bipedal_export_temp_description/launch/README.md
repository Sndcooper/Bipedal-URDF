# Launch Files (`bipedal_export_temp_description/launch`)

Python launch scripts for testing raw CAD export models in RViz 2 and Gazebo.

## Launch Scripts
- **`display.launch.py`**: Spawns `robot_state_publisher`, `joint_state_publisher_gui`, and RViz 2 with raw exported model (`bipedal_export_temp.xacro`).
- **`gazebo.launch.py`**: Spawns the raw CAD export into Gazebo physics simulation.
